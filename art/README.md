# art/

PROMPT.md §14 pipeline folders. `palette.gpl` is the shared 48-colour palette (provisional until the
art phase locks it); `provenance.json` records source, prompt, date and licence for every image
`pnpm art:qa` checks. `batches/` holds prompt packs, `inbox/` the downloads, `processed/` the atlases;
`raw/` is git-ignored. Nothing here is drawn by hand in Phase 0.
